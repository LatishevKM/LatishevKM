# Задача: WingLine L — складные фасады

## Входные данные

| Параметр | Значение |
|---|---|
| Система | Hettich WingLine L |
| Тип | Складные фасады |
| Количество створок | 2 шт |
| Высота | 2600 мм |
| Ширина створки | 390 мм |
| Нижняя направляющая | **Нет** (запрос заказчика) |

Ориентировочный проём по ширине: **≈ 780 мм** (две створки 390+390, без учёта зазоров/наложения — уточнить по схеме накладной/вкладной).

Оценка веса одной створки (МДФ 16 мм, плотностьсть ~700 кг/м³): **≈ 11,4 кг**.  
При 18 мм или тяжёлой отделке вес быстро уходит к лимиту 12 кг и выше.

## Вердикт по комплектации

**Запрошенная схема (H=2600 + без нижней направляющей) не соответствует лимитам Hettich.**

| Вариант | Высота | Вес створки | Нижняя направляющая | Подходит? |
|---|---|---|---|---|
| WingLine L Light | до 2400 мм (часто комплекты до 1700) | ≤ 12 кг | не обязательна | Нет — высота 2600 |
| WingLine L Heavy | до 2600 мм | ≤ 25 кг | **обязательна** | Да — но только с нижней |

### Что делать

1. **Рекомендуемый путь:** комплект **WingLine L Heavy** на диапазон **H2400–2600 / L250–600 / до 25 кг**, **с нижним роликом и нижней направляющей**.
2. Для **2 створок** (одна складная дверь) — **1 комплект** фурнитуры нужной стороны (лево/право) + комплект профилей (обычно **1200 мм**, подрезать).
3. Средние петли: при H=2600 — **3 шт** на дверь (комплект из трёх).
4. Корпусные петли: рекомендуется **Sensys 110°**.
5. Если заказчик категорически против направляющей на полу — обсудить **скрытый монтаж нижней направляющей сверху (внутрь модуля)**. Важно: при таком монтаже **левый и правый комплекты меняются местами** (нижний ролик не переворачивается).

### Если настаивают «совсем без нижней»

Нужно менять геометрию:

- высота створки **≤ 2400 мм**;
- вес створки **≤ 12 кг**;
- комплект Light **без нижнего ролика**.

При сохранении H=2600 мм такой вариант **нельзя** позиционировать как штатный WingLine L.

## Сторона открывания

В задаче не указана. Уточнить до заказа: **левая** или **правая** (со стороны фасада).

## Краткий порядок монтажа

1. Проверить корпус, зафиксировать от опрокидывания.
2. Верхний ходовой профиль.
3. Нижняя направляющая (или скрытый верхний монтаж направляющей).
4. Петли на боковину + средние петли между створками.
5. Ходовой элемент / нижний ролик → навеска → регулировки.
6. При необходимости механизм Push/Pull to Move и фиксатор.
7. Проверка хода и зазоров.

## Запуск калькулятора

```bash
pip install streamlit
streamlit run wingline/app.py
```
