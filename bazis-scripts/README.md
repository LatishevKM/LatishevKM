# Скрипты для Базис-Мебельщик 2025 x64

Каркас логики и рабочие примеры под встроенный редактор скриптов  
**Инструменты → Редактор скриптов (v20)** · движок **Node.js v22.14.0** · API ≈ 5.

## Как запускать

1. Открой модель в Базис-Мебельщик 2025 (x64).
2. Открой редактор скриптов.
3. Вставь содержимое файла из `examples/` (или подключи через `require`, если путь доступен движку).
4. Запусти скрипт на открытой модели.

> Скрипты здесь **не** исполняются в Node на Linux — только внутри Базиса на Windows.

## Логика (общий пайплайн)

```text
вход → валидация модели → обход дерева → фильтр панелей
     → действие (выделить / отчёт / изменить)
     → сообщение пользователю → выход
```

| Шаг | Модуль / API | Зачем |
|---|---|---|
| Данные модели | `currentFileData.model` | Корень дерева объектов |
| Обход | `obj.List` / `obj.Count` / `obj.Objects[i]` | Рекурсия по блокам и сборкам |
| История | `historyOperations.CommitCurrentChanges` | Одна отмена на результат скрипта |
| UI | `UI.dialogs.MessageBox` / `ErrorBox` | Сообщения об ошибках и итоге |
| Выделение | `model.UnPickAll()` / `obj.Selected = true` | Показать найденные объекты |
| Позиции | `arrangePositions` | Расстановка позиций/обозначений |

## Структура

```text
bazis-scripts/
  lib/
    model-walk.js      — обход модели, фильтр панелей
    panel-butts.js     — проверка облицовки кромки
  examples/
    select-panels-without-butts.js  — выделить панели без кромки
    panel-inventory-report.js       — отчёт по панелям модели
    arrange-positions-run.js        — расстановка позиций
```

## Важно для 2025 x64

- Старые скрипты (до Node-движка) могут не работать без правок.
- После `modelIOOperations` загрузки новой модели старые ссылки на объекты недействительны.
- Имена свойств кромки (`Butts` / элемент контура) могут отличаться по сборке — в `panel-butts.js` есть запасные проверки; при расхождении подправь под свою версию API (`apiVersion.GetRealScriptApiVersion()`).
